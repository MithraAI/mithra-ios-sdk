# Mithra iOS SDK

Swift Package for the Mithra iOS SDK. The package wraps the prebuilt
`MithraAnalytics` and `MithraAnalyticsNotificationService` XCFrameworks
served from `https://sdk.mithra.com/ios/`.

## Install

In Xcode choose **File > Add Package Dependencies...**, enter

```
https://github.com/MithraAI/mithra-ios-sdk
```

and pick **Up to Next Major Version**. Add `MithraAnalytics` to your app
target and `MithraAnalyticsNotificationService` to your Notification
Service Extension target.

Or, in `Package.swift`:

```swift
.package(url: "https://github.com/MithraAI/mithra-ios-sdk", from: "1.1.2")
```

## Releases

`Package.swift` in this repository is generated by the release workflow of
the SDK source repository. Each release rewrites the manifest with the
versioned archive URLs and their checksums and tags the commit `v<version>`.
Do not edit it by hand.
